## Contributing

We suggest you use **SMALL** PRs, so review is easy.
We also suggest that you get familiar with the project (or at least manifest semantics) before editing anything.

Here are some good first projects:
* Migrating tests from `nightbuild.toml` to `BUILD.nb`
* Improving documentation
* Making a generate PGO profiles script

Please do not add third party dependencies, open an issue instead.
Please do not bloat the software or make architecture changes. For architecture changes, open an issue.
