THE IDEA

Your build system shouldn't become the project.

NightBuild keeps the machinery small and the workflow direct. Define your targets, generate the build database, and build. That's the idea.

01

Native

Written in C++23 and designed around native toolchains. NightBuild is a build tool, not a layer of scripting wrapped around one.

02

Parallel

Independent compilation work runs concurrently, turning large source trees into a stream of useful work instead of a queue.

03

Incremental

Rebuild what needs rebuilding. Leave everything else alone. Keep iteration focused on the code you're actually changing.

04

No IDE required

NightBuild lives comfortably in the terminal. Use your editor, your shell, and your toolchain without handing the build over to an IDE.

05

Generated once

Define your project with BUILD.nb, configure it with args.nb, and generate a concrete command database. Build execution works directly from that graph.

06

Small machinery

The build system should support the project—not become another project you have to maintain.
